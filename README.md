# Commodore 64 External Power Supply 902503-02

The illustrated project description is available on the [Commodore 64 Power Supply GitHub Pages website](https://pdbuchan.github.io/commodore-64-power-supply/).

This repository documents a repairable Commodore 64 external power supply, Commodore part number **902503-02**. It contains a schematic, photographs of the enclosure and internal components, repair notes, and component datasheets.
